# Baumanka GeoGuessr

Локальная игра по типу GeoGuessr для главного здания Бауманки: игрок смотрит фотографию, выбирает этаж, кликает точку на схеме и получает очки за точность.

## Что уже сделано

- Python + PySide6 + SQLite.
- Главное меню на русском языке.
- Регистрация и вход по никнейму/паролю.
- Смена пользователя из главного меню.
- Игра на 6 раундов.
- Выбор этажа через выпадающий список.
- Карта открывается в отдельном фиксированном окне 1100×700.
- После клика показывается результат: правильная точка, выбранная точка, расстояние, штраф за этаж и очки.
- Финальный счёт можно сохранить.
- Есть история результатов.
- Есть редактор этажей и меток.
- В проект уже добавлены стартовые схемы 2 и 3 этажей из приложенных изображений.

## Как добавлять этажи

1. Открыть главное меню.
2. Нажать **Редактор**.
3. Перейти во вкладку **Этажи**.
4. Указать номер этажа.
5. Выбрать схему строго **1100×700**.
6. Задать масштаб.
7. Нажать **Сохранить этаж**.

По умолчанию используется масштаб `0.1 м/пикс`, то есть 10 пикселей равны 1 метру. Масштаб хранится отдельно для каждого этажа, поэтому его можно откалибровать позже.

## Как добавлять фотографии и правильные точки

1. Открыть **Редактор**.
2. Перейти во вкладку **Метки**.
3. Нажать **Выбрать фотографию**.
4. Выбрать этаж.
5. Нажать **Поставить точку на схеме**.
6. Кликнуть правильное место на карте.
7. Нажать **Сохранить метку**.

Фотография автоматически копируется в `data/photos/`, а в базе хранится путь к ней. Вручную писать SQL не нужно.

Поддерживаемые форматы изображений:

```text
.png, .jpg, .jpeg, .webp, .bmp
```

## Формула расстояния

Горизонтальное расстояние считается по прямой между двумя точками:

```text
distance = sqrt((answer_x - guessed_x)^2 + (answer_y - guessed_y)^2) * meters_per_pixel
```

Если этаж выбран неправильно, добавляется штраф:

```text
distance += 4 * abs(correct_floor - guessed_floor)
```

## Очки

```text
< 5 м   -> 5 очков
< 10 м  -> 4 очка
< 20 м  -> 3 очка
< 30 м  -> 2 очка
< 40 м  -> 1 очко
>= 40 м -> 0 очков
```

За одну игру максимум: `6 * 5 = 30` очков.

## Информационная безопасность

В проекте нет хранения паролей в открытом виде.

Используется:

- `PBKDF2-HMAC-SHA256`;
- отдельная случайная соль для каждого пользователя;
- 240 000 итераций хеширования;
- безопасное сравнение хешей через `hmac.compare_digest`;
- параметризованные SQL-запросы вместо склейки строк;
- нейтральная ошибка входа: «Неверный никнейм или пароль»;
- временная блокировка после нескольких неверных попыток.

Важно: это локальное учебное приложение. Если злоумышленник получает полный доступ к компьютеру и файлу базы, он сможет пытаться подбирать пароль офлайн. Для учебного проекта текущая схема уже заметно лучше хранения пароля обычным текстом.

## Что нужно для полноценной игры

В редакторе нужно добавить минимум **6 меток**. После этого кнопка **Начать игру** будет запускать полноценную игру из 6 случайных фотографий.
