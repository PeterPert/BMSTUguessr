# Baumanka GeoGuessr

Локальная игра по типу GeoGuessr для главного здания Бауманки: игрок смотрит фотографию, выбирает этаж, ставит точку на схеме и получает очки за точность.

## Возможности

- **Python + PySide6 + SQLite** — десктопное приложение без сервера.
- **Главное меню** на русском языке: игра, редактор, настройки, правила, результаты.
- **Регистрация и вход** по никнейму и паролю, смена пользователя из меню.
- **Игра на 6 раундов** — случайные фотографии из базы меток.
- **Карта 1100×700** — фиксированный размер, чтобы координаты не «плавали».
- **Результат после каждого раунда** — расстояние, штраф за этаж, очки, карта с метками.
- **Метки в стиле метро** — красная (ваш ответ) и зелёная (правильная точка).
- **Крупная карта результата** под фото; можно открыть на весь экран.
- **Автосохранение** итога после последнего раунда.
- **Редактор** этажей и меток с предпросмотром фото.
- **Настройки оформления** — цвет каждого элемента интерфейса на выбор.
- **История результатов** по всем игрокам.
- Стартовые схемы **2** и **3** этажей уже включены в проект.

## Установка

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS / Linux:

```bash
source .venv/bin/activate
```

Затем:

```bash
pip install -r requirements.txt
python main.py
```

Требуется **Python 3.10+** и **PySide6**.

## Быстрый старт

1. Запустить `python main.py`.
2. Зарегистрироваться или войти.
3. Открыть **Редактор** и добавить минимум **6 меток** (фото + этаж + точка на карте).
4. Нажать **Начать игру**.

## Редактор

### Этажи

1. Главное меню → **Редактор** → вкладка **Этажи**.
2. Указать номер этажа и масштаб (по умолчанию `0.1` м/пикс — 10 px = 1 м).
3. Нажать **Выбрать схему** — файл строго **1100×700** px.
4. Нажать **Сохранить этаж**.

Масштаб хранится отдельно для каждого этажа.

### Метки

1. Вкладка **Метки**.
2. Ввести название, нажать **Фото**, выбрать этаж.
3. Нажать **Точка на карте** и кликнуть правильное место.
4. При необходимости — **Проверить** (как будет выглядеть раунд).
5. Нажать **Сохранить**.

Фото копируется в `data/photos/`, путь сохраняется в базе. SQL вручную не нужен.

Поддерживаемые форматы: `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`.

## Настройки оформления

Главное меню → **Настройки** → вкладка **Оформление**.

Можно изменить цвета:

- фона, текста, заголовков;
- кнопок (основных и вторичных);
- полей ввода, карточек, таблиц, вкладок;
- меток на карте (ваш ответ / правильная точка / линия).

Справа — **живое превью**. Кнопка **Применить** сохраняет тему в `data/theme.json` и применяет ко всему приложению. **Сбросить** возвращает стандартные цвета.

## Игра

1. Выбрать этаж в списке.
2. Нажать **Карта** и поставить точку.
3. После клика — результат раунда и карта с метками.
4. **Следующий раунд** — до 6 раундов.
5. После 6-го раунда итог **сохраняется автоматически**.

### Формула расстояния

Горизонтальное расстояние по прямой:

```text
distance = sqrt((answer_x - guessed_x)² + (answer_y - guessed_y)²) × meters_per_pixel
```

Штраф за неверный этаж:

```text
distance += 15 × |correct_floor - guessed_floor|
```

### Очки

| Расстояние | Очки |
|------------|------|
| < 5 м      | 5    |
| < 10 м     | 4    |
| < 20 м     | 3    |
| < 30 м     | 2    |
| < 40 м     | 1    |
| ≥ 40 м     | 0    |

Максимум за игру: **30** очков (6 × 5).

## Безопасность

Пароли не хранятся в открытом виде:

- `PBKDF2-HMAC-SHA256`;
- отдельная соль на пользователя;
- 240 000 итераций;
- сравнение хешей через `hmac.compare_digest`;
- параметризованные SQL-запросы;
- нейтральная ошибка входа: «Неверный никнейм или пароль»;
- временная блокировка после нескольких неверных попыток.

Это локальное учебное приложение: при полном доступе к компьютеру и файлу базы возможен офлайн-подбор пароля.

## Что нужно для полноценной игры

В редакторе — минимум **6 меток**. После этого **Начать игру** запускает полную игру из 6 случайных фотографий.
