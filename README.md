# 🧭 Baumanka GeoGuessr

**Baumanka GeoGuessr** — это локальная десктопная игра, созданная по мотивам популярной игры GeoGuessr, но адаптированная под Главное Учебное Здание (ГУЗ) МГТУ им. Н.Э. Баумана.

Игроку предлагается случайная фотография из аудиторий или коридоров университета. Его задача — определить, на каком этаже сделан снимок, указать точное место на интерактивной схеме здания и набрать максимальное количество очков за точность попадания.

---

## ✨ Ключевые возможности

*   **🎮 Увлекательный игровой процесс** — игра состоит из 6 раундов со случайной выборкой мест из базы данных.
*   **🗺️ Интерактивная карта** — детальные поэтажные планы фиксированного разрешения (1100×700 px) для идеальной калибровки координат.
*   **🛠️ Встроенный редактор** — удобный интерфейс администратора для добавления новых этажей, масштабирования карт и разметки новых игровых точек прямо в приложении.
*   **🎨 Кастомизация оформления** — встроенные настройки цветовой схемы (темы оформления) с живым предпросмотром изменений.
*   **📊 История результатов** — локальная таблица лидеров с сохранением детальной статистики каждого раунда.
*   **🔒 Повышенная безопасность** — безопасная авторизация администраторов с шифрованием паролей по современным стандартам.
*   **🚀 Готов к старту** — базовые планы этажей ГЗ МГТУ им. Н.Э. Баумана уже включены в поставку.

## 🛠️ Установка и запуск

Для работы приложения необходим **Python версии 3.10+**.

### 1. Клонирование и подготовка окружения
Перейдите в папку с проектом и создайте виртуальное окружение:

```bash
# Создание виртуального окружения
python -m venv .venv

# Активация окружения:
# Для macOS / Linux:
source .venv/bin/activate
# Для Windows (PowerShell):
.venv\Scripts\Activate.ps1
# Для Windows (CMD):
.venv\Scripts\activate.bat
```

### 2. Установка зависимостей
Установите библиотеку **PySide6** (официальная обёртка Qt для Python):

```bash
pip install -r requirements.txt
```

### 3. Запуск приложения
Запустите главный скрипт проекта:

```bash
python main.py
```

## 🐳 Запуск через Docker

Альтернативный способ запуска — Docker-контейнер. Все зависимости уже внутри образа.

### Сборка образа

```bash
docker build -t bmstuguessr .
```

### Запуск (Linux)

```bash
# Разрешить Docker доступ к X11
xhost +local:docker

# Запуск через Docker Compose
docker compose up

# Или напрямую
docker run --rm -it \
    -e DISPLAY=$DISPLAY \
    -v /tmp/.X11-unix:/tmp/.X11-unix:rw \
    -v bmstuguessr-data:/app/data \
    --network host \
    bmstuguessr
```

### Запуск (Windows / WSL2)

1.  Установите X-сервер (например, [VcXsrv](https://sourceforge.net/projects/vcxsrv/) или [X410](https://x410.dev/)).
2.  Запустите VcXsrv с опцией **Disable access control**.
3.  Запустите контейнер:

```bash
docker compose --profile windows up
```

> **Примечание:** Данные игры (база данных, фото, темы) сохраняются в Docker volume `bmstuguessr-data` между запусками.

## 🚀 Быстрый старт для игры

1.  **Запустите** приложение (`python main.py`).
2.  **Зарегистрируйте** аккаунт администратора или водите под существующим.
3.  Перейдите в **Редактор** и добавьте как минимум **6 игровых меток** (загрузите фото, выберите этаж и укажите его координаты кликом на карте).
4.  Вернитесь в главное меню и нажмите **Начать игру**!

## 📖 Подробное руководство по редактору

Редактор позволяет расширять игровую базу прямо из графического интерфейса.

### Добавление планов этажей
1.  Перейдите во вкладку **Этажи** в Редакторе.
2.  Укажите номер этажа и задайте масштаб (по умолчанию `0.1` метров на пиксель, т.е. 10 пикселей = 1 метр).
3.  Нажмите **Выбрать схему** и выберите изображение планировки.
    *   *Важно:* Изображение должно иметь разрешение ровно **1100×700** пикселей.
4.  Нажмите **Сохранить этаж**.

### Добавление игровых локаций (меток)
1.  Перейдите во вкладку **Метки** в Редакторе.
2.  Введите название (описание) точки, нажмите **Фото** для загрузки изображения и выберите соответствующий этаж.
3.  Нажмите **Точка на карте** и кликните левой кнопкой мыши по верной позиции на плане этажа.
4.  *(Опционально)* Нажмите **Проверить** для предпросмотра раунда.
5.  Нажмите **Сохранить**.
    *   Приложение автоматически скопирует фотографию в директорию `data/photos/` с уникальным именем и добавит запись в базу данных.

## 🧮 Механика подсчета очков

### Расчет расстояния

1. **Расстояние на плоскости** (в пикселях) переводится в метры согласно масштабу текущего этажа:
   ```text
   Расстояние (м) = √( (X_ответ - X_клик)² + (Y_ответ - Y_клик)² ) × Масштаб (м/пиксель)
   ```

2. **Штраф за этаж**: при указании неверного этажа начисляется **штрафное расстояние** (по 15 метров за каждый этаж разницы):
   ```text
   Итоговое расстояние = Расстояние (м) + 15 × |Верный_этаж - Выбранный_этаж|
   ```

### Начисление очков

Очки за каждый раунд начисляются в зависимости от итогового расстояния:

| Итоговое расстояние (м) | Набираемые очки |
| :---: | :---: |
| **Менее 5 м** | ⭐⭐⭐⭐⭐ (5 очков) |
| **От 5 м до 10 м** | ⭐⭐⭐⭐ (4 очка) |
| **От 10 м до 20 м** | ⭐⭐⭐ (3 очка) |
| **От 20 м до 30 м** | ⭐⭐ (2 очка) |
| **От 30 м до 40 м** | ⭐ (1 очко) |
| **40 м и более** | ❌ (0 очков) |

*Максимально возможный счет за одну игру:* **30 очков** (6 раундов × 5).

## 🔒 Безопасность данных

Приложение разработано с учетом правил безопасной разработки программного обеспечения:
*   **Хеширование паролей:** Пароли администраторов не хранятся в открытом виде. Для защиты используется стойкий алгоритм `PBKDF2-HMAC-SHA256` с уникальной криптографической солью для каждого пользователя и 240 000 итерациями.
*   **Безопасная сверка:** Сравнение хешей при входе выполняется с помощью константного по времени алгоритма `hmac.compare_digest` для защиты от атак по времени (timing attacks).
*   **Защита от SQL-инъекций:** Все запросы к SQLite параметризованы.
*   **Предотвращение перебора (Brute Force):** Приложение блокирует учетную запись администратора на 60 секунд после 5 неудачных попыток входа подряд.
*   *Примечание:* Это учебный локальный проект. Файл базы данных хранится на вашем компьютере, поэтому для защиты данных также используйте разграничение доступа в ОС.
